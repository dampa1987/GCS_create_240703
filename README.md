# スペースインベーダーゲーム

ブラウザで動作するクラシックなスペースインベーダーゲームです。

## 🎮 遊び方

### ゲームの開始
1. `index.html` をブラウザで開く
2. 「ゲームスタート」ボタンをクリック

### 操作方法
- **← →（矢印キー）**: プレイヤーを左右に移動
- **スペースキー**: 弾を発射

### ゲームルール
- インベーダーを全て倒すとレベルアップ
- 敵の弾に当たるとライフが減る
- ライフが0になるとゲームオーバー
- インベーダーがプレイヤーに到達してもゲームオーバー
- スコアは倒したインベーダーのタイプによって変わります

## 📁 ファイル構成

```
├── index.html   # メインのHTMLファイル
├── game.js      # ゲームロジック
├── style.css    # スタイリング
└── README.md    # このファイル
```

## 🚀 起動方法

### 方法1: ブラウザで直接開く
`index.html` をダブルクリックしてブラウザで開く

### 方法2: ローカルサーバーを使用
```bash
# Python 3を使用する場合
python -m http.server 8000

# その後、ブラウザで以下にアクセス
# http://localhost:8000
```
